# 🏎️ Pit Wall | GP de São Paulo 2026

Landing page temática desenvolvida para o **Grande Prêmio de São Paulo de Fórmula 1 (2026)** no Autódromo de Interlagos. O projeto reúne informações da pista, grid de pilotos em destaque, tabela de classificação do campeonato e um formulário interativo para reserva de ingressos.

---

## 📋 Funcionalidades e Seções

* **Hero & Dados do Circuito:** Apresentação visual do evento com informações técnicas de Interlagos (71 voltas, 4.309 km por volta e 15 curvas) e botões de acesso rápido.
* **01. Grid de Pilotos:** Cards estilizados com as cores oficiais das equipes (Ferrari, McLaren, Mercedes e Audi), exibindo o número e o nome dos pilotos em destaque, incluindo o brasileiro Gabriel Bortoleto.
* **02. Classificação:** Tabela completa com posição, piloto, escuderia, número de vitórias, diferença para o líder e pontuação geral, acompanhada de campos de busca e filtro por equipe.
* **03. Ingressos:** Tabela de valores por setor (*Arquibancada A*, *Setor da Reta* e *Box VIP*), aviso de disponibilidade limitada e formulário completo de reserva (com escolha de dia, quantidade, envio de foto para o telão e recado para o piloto).
* **Design Responsivo:** Layout adaptado para dispositivos desktop, tablets e smartphones.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo e formulários.
* **CSS3:** Estilização moderna com variáveis CSS (`:root`), Flexbox, CSS Grid, gradientes personalizados e Media Queries para responsividade.
* **Google Fonts:** Tipografia *Titillium Web* para reforçar a identidade visual do automobilismo.


2. Certifique-se de que a imagem `piloto.jpg` esteja dentro da pasta `img/`.
3. Abra o arquivo `index.html` diretamente no seu navegador de preferência (ou utilize a extensão *Live Server* no VS Code).
